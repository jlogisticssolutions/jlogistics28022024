# Security Policy

## Scope

JEM Logistics Solutions is a static website hosted through GitHub Pages. The
website source is maintained in this repository.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately to:

**info@jemlogisticssolutions.com**

Use the subject line **Website Security Report**. Include the affected page or
file, a clear description of the issue, steps to reproduce it, and supporting
evidence. Do not include passwords, access tokens, or customer personal data.

We aim to acknowledge reports within five business days and provide an initial
assessment or status update as soon as reasonably possible.

Please do not publicly disclose an unpatched vulnerability. We will review
the report, assess its impact, and determine whether a fix or mitigation is
required. We may request additional information.
